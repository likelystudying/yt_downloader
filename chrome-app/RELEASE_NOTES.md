**YT Downloader for Chrome**: download YouTube videos (MP4) and audio (MP3) from Chrome or Edge, with no
Terminal or command prompt.

| Download | For |
|---|---|
| `YT-Downloader-Setup.exe` | Windows 10/11 (64-bit). Run it; if Windows says it protected your PC, click **More info → Run anyway**. |
| `YT-Downloader-mac.zip` | Apple Silicon Macs (M1 or newer), macOS 12+. Unzip, drag into Applications, open it (first time: System Settings → Privacy & Security → Open Anyway). |

Then add the extension in `chrome://extensions` (Developer mode → Load unpacked); the app copies the
folder's location for you. Full steps: [chrome-app/README.md](https://github.com/likelystudying/yt_downloader/blob/main/chrome-app/README.md).
